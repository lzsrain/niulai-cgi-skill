# 牛来 风格系统 (style-system)

本文件定义"牛来"廉价 CGI 美学的**可操作支柱**与**命名预设**。所有内容均来自对
真实生成结果的试错校准，而非泛泛描述。

> 概念灵感来自 `TanShilongMario/NiuLai-Skill`（该仓库无许可证，仅作概念参考）。

## 一、七条不可妥协的"破味"信号

少一条就会回到"干净的 low-poly"，被判定为**不是牛来**：

1. **逐面纯色平面着色**：每个多边形面只有一种纯色，无渐变、无高光、无平滑
   着色、无 PBR、无法线贴图、无反射、无环境光遮蔽（AO）。
2. **无抗锯齿**：多边形边缘是锯齿状、阶梯状的，不是平滑的。
3. **水是平涂色块**：湖/河/泉池是**不透明的纯色矩形/圆盘**，无水波、无涟漪、
   无镜面高光、无透明度。
4. **可数贴图**：墙面覆盖清晰平铺、能**数得清**的 16×16 重复砖纹（像低分辨率
   2-bit 像素贴图被拉伸铺上去）。
5. **单硬光源 + 硬阴影 blob**：右上角一盏未经塑形的硬方向光，在平地投下**纯黑
   实心斑块阴影**，无柔和半影。
6. **破比例 + 穿模**：比例刻意失调，可见穿插/穿模（墙插进屋顶、地面插穿脚）。
   资产明显复用。
7. **明亮平涂塑料感配色**：钴蓝、褪色砖红、赭石、淡青、桃米色；天空是**无渐变
   的灰白带**，像贴上去的背景。

## 二、命名预设

### `sunlit_game_map`（建筑 / 城市地图 / 场景）
用于地图、俯视/斜俯视城市场景、游戏底图。重点：
- 粗几何、破比例、可见穿模、粗糙小贴图、单光源、廉价渲染。
- 天空无渐变；水面平涂不透明；墙面 16×16 可数砖。
- 适合把"真实城市地图"重做成"早期 3D 渲染但构图不变"的样子。

### `character`（人物 / 动物角色）
用于向导角色、NPC、动物。重点：
- 圆滑着色的**连续**身体（不要分段木偶关节、不要方块体素）。
- 低劣感来自比例失调、权重拉扯、关节塌陷、穿模、困倦失焦的眼神、不协调动作——
  而不是外露的插接结构。
- 眼睛接近人的"半闭失焦眼"：上眼皮下垂、左右开合不一、小瞳孔偏低偏侧、视线不
  汇聚。不要外挂的大白球眼睛。
- 动物降肌肉感但不极端减面，保持连续圆滑大形。
- **角色图务必生成在纯绿幕 `#00ff00` 背景上**，便于在引擎里抠成透明。

## 三、反向质量门槛（何时判定失败）

出现以下任一，视为"不够牛来"，应重出或如实说明：
- 太漂亮 / 太准确 / 太协调 / 太还原（像成熟动画）。
- 人物木偶化（分段圆柱、插销、球关节、悬浮肢体）。
- 服装桶装化 / 眼睛卡通球化。
- 动物肌肉过强（健美、英雄化、低模解剖展示）。
- 毛发变成真实纤维（只能是凹凸/法线贴图伪造的廉价毛感）。
- 背景只用纯色或重复过度（应复用少量低分辨率漫反射贴图）。
- 用像素化 / 模糊 / VHS / 重度噪点 / 暗调当主要劣化手段（这是滤镜，不是牛来）。

默认最多重试两次；仍有硬伤就如实说明，不要硬说成功。
